주요 기능

주식 투자에 필요한 모든 정보를 한 화면에

📊
실시간 지수 모니터링
KOSPI · KOSDAQ · S&P500 · NASDAQ · DJI를 실시간으로 추적. 전광판 스크롤로 한눈에 파악.
📈
TradingView 차트
MA · 볼린저 · RSI · MACD 지표 탑재. 1개월~10년 기간 선택. 국내/미국 모두 지원.
🔍
RSI 다이버전스 분석
KOSPI·KOSDAQ 전체 종목과 S&P500 상위 150개 종목에서 상승/하락 다이버전스를 자동 탐지.
👥
투자자 동향
외국인·기관·개인 순매수/순매도 동향. 종목별 10일 투자자 매매 히스토리 제공.
💹
ADR 등락비율
KOSPI·KOSDAQ 상승/하락 종목 수 비율로 시장 강도를 측정. 강세장/약세장 판단 지표.
🤖
AI 채팅 어시스턴트
NVIDIA Nemotron LLM 기반 시장 분석 채팅. 실시간 데이터 컨텍스트로 답변 제공.
🌐
다국어 뉴스
국내외 금융 뉴스를 RSS로 수집하고 AI로 한국어 자동 번역. 최신 시장 동향 파악.
⏰
NYSE 개장 카운트다운
미국 장 개장까지 남은 시간을 실시간 카운트다운. 프리장/시간외 가격도 표시.
₿
암호화폐
BTC · ETH · XRP 실시간 가격 및 차트. CoinGecko API 연동, 약 60초 단위 갱신.

빠른 시작

로컬에서 3단계로 실행

1. 저장소 복제bash
git clone https://github.com/white4311-spec/stock-page.git
cd stock-page
2. 환경변수 설정.env
# .env 파일 생성 후 API 키 입력
OPENROUTER_API_KEY=sk-or-...
KIS_APP_KEY=your-kis-key
KIS_APP_SECRET=your-kis-secret
3. 실행 (원클릭)PowerShell
# 백엔드 + 프론트엔드 동시 실행
.\start.ps1

# 브라우저: http://localhost:5173
# API 문서: http://localhost:8001/docs
